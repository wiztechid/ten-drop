# TEN DROP

**Ten Drop: Number Puzzle** — a one-thumb number puzzle built around live dropping, complementary pairs that make 10, gravity and satisfying cascades.

## Current Stage

Playable Prototype **v0.3** — in development.

## Canonical Project State

Read [docs/CURRENT.md](docs/CURRENT.md).

## Current Rule

Pairs clear when orthogonally touching numbers sum to 10:

**1+9 · 2+8 · 3+7 · 4+6 · 5+5**

## Production Rule

Prototype and validate the core loop before Android production or AdMob integration.
