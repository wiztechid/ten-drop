# TEN DROP — v0.3 PLAYABLE SPEC

Status: IMPLEMENTED ON PROTOTYPE BRANCH

## Vertical slice
- 6×9 live-drop board.
- Left/right/hard drop via buttons, keyboard and swipe.
- Complement-to-10 orthogonal matching.
- Gravity and repeated cascade resolution.
- Two-copy shuffled 1–9 Fair-Bag prototype.
- Immutable NOW + NEXT + NEXT queue.
- Jelly Numberlings using CSS placeholder art.
- Cascade callouts: 10!, TEN-TASTIC!, FEVER 10!, PERFECT TEN!.
- Five objective levels and Chapter Clear natural-break placeholder.
- High score in localStorage.
- No ads, tracking, login or external dependencies.

## QC targets
1. Touch response and hard-drop feel.
2. Number readability on a real phone.
3. Whether 6×9 creates enough planning space.
4. Whether Fair-Bag feels fair rather than scripted.
5. Cascade frequency and emotional payoff.
6. Objective pacing.
7. Whether the player voluntarily starts another run.

## Known prototype simplifications
- Numberlings are CSS jelly placeholders, not final 3D assets.
- Near-10 is currently represented by subtle brightness when an existing complement pair is present; deeper anticipatory eye behavior remains a visual iteration.
- Audio/haptics are intentionally deferred.
- FEVER 10 is feedback only; no temporary rule mutation yet.
- No analytics until the core loop is approved.
